# 右か、左か。

エスカレーターで次々に人をさばく、くだらないけどちょっと面白い風刺ゲーム。

東京では左に立ち、大阪では右に立つ。たったそれだけの違いで、脳は簡単にバグる。
行き先が切り替わるたびに左右が真逆になる駅で、あなたは何人さばけますか？

## 遊び方

- 現れた人を、立つ側のボタン（左／右）でさばくのが基本操作。スワイプやキーボード（←／→／↓）でも遊べます
- ふつうの人 → その街の「立つ側」へ
- 急いでいる人 → 空いている側へ通す
- 大きな荷物・手つなぎの人 → 「見送る」で次の便へ
- 1回でも詰まらせたら、そこで終わり

## ステージ

1. **東京** — 左に立つ、右を空ける
2. **大阪** — 右に立つ、左を空ける（全部逆）
3. **新幹線** — 行き先が1人ごとに入れ替わる
4. **名古屋** — ……？（20人さばいた先でお会いしましょう）

100人さばけたら伝説です。32人で踏破クラス、50人で猛者。

## ほんとうのこと

このゲームは片側空けの慣習を面白がっていますが、本来エスカレーターは
左右どちらでも「立ち止まって乗る」のが安全な乗り方です。
名古屋市のように「両側に立って利用を」と条例で呼びかける街も出てきました。
次に乗るときは、手すりにつかまって、ちょっと景色でも眺めてみてください。

## 技術

- 単一HTMLファイル（`index.html`）だけで動きます。ビルド不要
- BGM・効果音は Web Audio API で合成（音声ファイルなし）
- デプロイは Cloudflare Pages を想定
